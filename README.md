# 🧬 BioҰБТ — биологиядан ҰБТ-ға дайындық платформасы

Түлектерге (16–18 жас) арналған, телефон мен планшетке толық бейімделген, жылдам жұмыс істейтін веб-тест.
Фреймворксіз (таза HTML/CSS/JS), сондықтан бірден ашылады және кез келген статикалық хостингте жұмыс істейді.

## Іске қосу
- **Жергілікті:** `python3 -m http.server 8000` → http://localhost:8000
- **GitHub Pages:** Settings → Pages → Branch: `main` / root. Сайт `https://<user>.github.io/biology/` мекенжайында ашылады.

## Өз сұрақтарыңды .docx-тен қосу
```bash
pip install python-docx
python3 tools/docx_to_questions.py сұрақтар.docx   # js/questions.js қайта жазылады
```
.docx форматы:
```
# Цитология
Контекст: (міндетті емес) контекстік мәтін
1. Сұрақ мәтіні
A) Нұсқа
*B) Дұрыс нұсқа        ← * / + белгісі немесе қалың қаріп
C) Нұсқа
Түсініктеме: Неліктен B дұрыс
```

## ✏️ Өзгертетін нәрселер — қай файлда?
| Не өзгертесіз | Файл |
|---|---|
| Сайт атауы, басты беттегі тақырып/мәтін, мұғалім аты, WhatsApp/Telegram/Instagram, оқушы пікірлері, тест саны мен уақыты, тариф, ҰБТ айлары, қалалар, келісім мәтіні | `js/config.js` |
| Тараулар (атауы, иконкасы, сипаттамасы), шпаргалкалар, есептер | `js/content.js` |
| Тест сұрақтары | `js/questions.js` (немесе .docx → `tools/docx_to_questions.py`) |
| Түстер мен дизайн | `css/style.css` (`:root` ішіндегі айнымалылар) |

Сұрақтағы `module` өрісі `js/content.js` ішіндегі тараудың `id`-імен бірдей болуы керек.

## Құрылым
```
index.html            — қосымша қабығы
js/config.js          — САЙТ БАПТАУЛАРЫ (мәтіндер, байланыс, параметрлер)
css/style.css         — дизайн (фиолет / Trust Blue / розовый CTA, dark mode)
js/questions.js       — сұрақтар қоры
js/content.js         — тараулар, шпаргалкалар, жетістік белгілері
js/app.js             — роутинг, авторизация, тест қозғалтқышы, балл, XP, статистика
tools/docx_to_questions.py — .docx → questions.js
```

## Ескерту
Деректер (аккаунттар, XP, статистика) әр оқушының өз браузерінде (`localStorage`) сақталады. Сондықтан:
- рейтингте тек сол құрылғыда тіркелген оқушылар көрінеді;
- оқушы басқа телефоннан кірсе, прогресі көшпейді.

Барлық оқушыларға ортақ рейтинг, SMS/Google/Telegram арқылы кіру және онлайн төлем үшін сервер (мысалы, Firebase/Supabase) қосу керек.
