# BioҰБТ — жұмыс тәртібі

Мұғалім — биология пәнінің мұғалімі, оқушыларды ҰБТ-ға дайындайды. Сайт: таза HTML/CSS/JS (фреймворксіз),
GitHub Pages арқылы `claude/clever-pasteur-jvnobc` тармағынан жарияланады. Деректер — Firebase (Auth + Firestore).

## Негізгі ережелер (міндетті)
1. **Әрдайым қазақша жауап бер.** Қысқа, нақты: не істелді, не тексерілді, мұғалім не тексеруі керек.
2. **Әр өзгерістен кейін:** `bash tools/bump.sh` (кэш нұсқасы) → `git add -A` → commit → `git push -u origin claude/clever-pasteur-jvnobc`. PR ашпа.
3. **Файл мазмұнына адал бол.** Сұрақ/жауапты өз білгеніңше өзгертпе. Тек анық теру қателерін түзетуге болады
   (қайталанған нұсқа, «Ы.» орнына «Б.», екі сұрақтың бірігіп кетуі). Күмәнді жауап болса — **файлдағыдай қалдырып, мұғалімге айт**.
4. **Жауабы белгіленбеген сұрақ болса** — алдымен файлды қайта тексер (✅, қалың қаріп, «+» белгісі, «Жауабы: 1–A, 2–C» тақырыбы).
   Мұғалім «жирныймен белгіленген» деп ескерткен — жауап көбіне қалың қаріпте. Шынымен жоқ болса ғана мұғалімнен сұра, нұсқаны жарияламай тұр.
5. **Жабық тесттерді** (tools/secret/*.enc) мұғалім «аш» демейінше ешқашан ашпа, сайтқа қоспа, мазмұнын көрсетпе.
6. **Тестілеу кезінде Firebase-ті міндетті түрде өшір** (`config.js`-ке `window.CONFIG.firebase.enabled=false` қосып route арқылы) —
   әйтпесе тест аккаунттары нағыз серверде жасалады. `scripts/e2e_folder.js` мұны өзі жасайды.
7. Нұсқа/тест қосқанда **бұрынғы нұсқалар өзгермеуі керек**: `git diff --stat` — тек қосылған жолдар болсын.
8. Соңында мұғалімге: не қосылды (саны, түрлері), қандай түзету жасалды, нені тексеріп беру керек.

## Құрылым
| Жол | Не |
|---|---|
| `js/app.js` | Бүкіл қосымша (бір IIFE): беттер, тест, балл (`scorePoints`), қатемен жұмыс, мұғалім кабинеті |
| `js/cloud.js` | Firebase: кіру, құрылғы бұғаты (`deviceId` + `deviceFp`), сақтау (`mergeFields`!), `flush()` |
| `js/tests/*.js` | `TEST_FOLDERS` (ҰБТ сынамасы бөлімінің папкалары): `nagyz`, `naurz`, `uto`, `ubtn` (ҰБТ нұсқалары), `prob` (Пробныйда келген) |
| `js/tests/chapters.js` | `CHAPTER_TESTS` — тараулық тесттер (тарау → тесттер; `exam: true` — бақылау тесті, `timeLimit` секундпен) |
| `js/images.js` | `IMAGE_FOLDERS` + `IMAGE_TASKS` — «Суретпен жұмыс» (жазуы жабылған суреттер, ұяшықтар `zones` %-пен) |
| `js/notes.js`, `js/plants.js`, `js/realubt.js` | «Негізгі жаттау керек ақпараттар», өсімдіктер, нағыз ҰБТ сұрақтары |
| `index.html` | Жаңа `js/tests/X.js` файлын осында `<script>` етіп қос (басқалардың жанына) |
| `tools/` | Түрлендіргіштер (төменде). `tools/sources/` — мұғалімнің бастапқы .docx файлдары |

### Сұрақ форматы
```js
{ id, module, type: "single"|"multi"|"context"|"match"|"label", q, options: [..], correct: [индекстер],
  context, contextTitle, contextImg: [..],        // контекстік (26–30)
  items: [{ text, answer }] | [{ text, answers: [..] }],  // сәйкестендіру (31–35); answers — көп әріпті (әр әріпке 1 балл)
  img: ["img/tests/<testId>/q12.png"] }
```
Балл: single 1; multi 2 (бәрі дұрыс 2, бір қате/жетіспеу 1, көп қате 0); match — әр жұпқа 1; label — әр ұяшыққа 1.

## 1. ҰБТ нұсқалары (`js/tests/ubtn.js`) — мұғалімнің «№» деп аталған .docx файлдары
Файлды `tools/sources/ubtn/vN.docx` етіп сақта (N — мұғалімнің файл нөмірі), `tools/ubtn/build.py`-ге қос
(топтар B/C тізімі, `--` docstring), сосын:
```bash
python3 -I tools/ubtn/build.py tools/sources/ubtn .
node .claude/skills/bioubt/scripts/brief.js js/tests/ubtn.js ubtn-16     # әр сұрақтың түрі/жауабы
```
`tools/ubt_docx.py` (жалпы оқырман) таниды: дұрыс жауап — қалың қаріп; сәйкестендіру — «Мәтін – В» немесе «Мәтін В»,
қалың нұсқалар, «Сәйкестендіру — Жауабы: 1–A, 2–C»; кіші латын әріптері `b)`; контекст — 26-сұрақтан бастап
(тақырып + мәтін немесе тақырып + сурет). Ескертулер шықса — `build.py`-ге нақты түзету қос (мысалдар бар: 31-сұрақ
сәйкестендіру, «Ы.» → «Б», бірігіп кеткен 27/28, қайталанған «Д. Отосклероз»).
Әр нұсқада 40 (кейде мұғалім файлында 41) тапсырма: 25 single, 5 context, 5 match, 5 multi.

## 2. «Пробныйда келген нұсқалар» (`js/tests/prob.js`)
Формат: «N. сұрақ», «A) нұсқа ✅», бөлімдер «І бөлім…», сәйкестендіру — `Варианттар: A) … · B) …` + кесте
(элемент | жауап). ✅ жоқ болса — қалың қаріп. Суреттер өз сұрағына, контекст мәтінінен кейінгі сурет — контекстке.
```bash
cp <файл> tools/sources/prob/pN.docx
python3 -I tools/prob/build.py . tools/sources/prob/p{1,2,...,N}.docx    # барлық файлды ретімен бер!
```
Түзетулер `FIX` (сұрақ мәтіні/нұсқа/сурет) және `IMGFIX` (суреттегі жауапты көрсететін қолжазбаны жабу, кесу, үлкейту).
**35-сұрақ «Популяция көрсеткіштері»**: нұсқалар мұғалімнің түпнұсқасындағыдай толық анықтама болуы керек (1-, 8-нұсқа мысалы).
Әр жаңа суретті **міндетті түрде қарап шық** (Read): жауапты ашып тұрған жазу, сұраққа сәйкес емес тақырып үзіндісі болмасын.

## 3. Тараулық тест (`js/tests/chapters.js`)
`tools/chapters/parse_ubt.py` (.docx → JSON) → `tools/chapters/build_ubt_chapter.py repo <module> t1.json …`
(`--append` — бар тесттерге тиіспей соңына қосу). Әр тараудың 1-тесті тегін, қалғаны премиум, ретімен ашылады.
Бақылау тесті: `"exam": true` (сұрақ/нұсқа реті араласады, жауаптар `history[].ans`-ке жазылады), уақыты `timeLimit`.

## 4. Жабық тесттер (`tools/secret/`)
AES-256-CBC, pbkdf2 200000. Ашу жолы `tools/secret/README.md`-де. Құпия сөзді тек мұғалім береді. Ашқаннан кейін
README-ге «… ашылды» деп жаз. Мұғалім қайта «жаб» десе — `chapters.js`-тен сол тестті және `img/chapters/<id>` алып таста.

## 5. «Суретпен жұмыс» (`js/images.js`)
- Суреттер **папкаларға** топталады (`IMAGE_FOLDERS`: id, module, title); әр тараудың 1-папкасы тегін.
- Түрлендіргіштер: `tools/images/build_images.py`, `build_veg.py` (ботаника), `build_anat.py` (анатомия + барлық папкалар
  тізімі `FOLDERS`, ескі тапсырмалардың папкасы `OLD`). Бастапқы PDF/сурет файлдары репода жоқ — жаңа суретті қосқанда
  мұғалімнің файлынан шығар (`pdfimages -png`), координатты тор салып анықта (50px тор → Read).
- Тапсырма: `(id, файл, папка, атауы, crop, pad(оң, асты), scale, clean, [(жауап, бокс[, тігінен])], [тек жабылатын])`.
  Бокс — бастапқы сурет пикселімен; жазу ақпен жабылады, сол орынға ұяшық. Нөмірлі суретте ұяшықтарды бос орынға
  `col()` / `grid()` арқылы нөмір ретімен қой. Сканерленген суретке `clean=True` (бет арқасы әріптерін ағартады).
- Арнайы: `zones[].n` — нөмір орнына әріп («а», «ә»); `zones[].g` — бір топтағы ұяшықтардың реті маңызды емес;
  `t["q"]` — өз сұрағы; қосымша алдайтын сөздер `t["options"] += [...]` (мысалы, pH графигі → «Пепсин»).
- Сурет файлын ауыстырсаң — **жаңа файл атымен** сақта (`FILE` map), әйтпесе браузер ескісін кэштен көрсетеді.
- Тексер: барлық папканы дұрыс жауаппен орындап шық (толық балл), бір-екі скриншот қарап шық.

## Тексеру (жариялау алдында міндетті)
```bash
(setsid nohup python3 -m http.server 8765 >/dev/null 2>&1 &)      # репо түбірінен
node .claude/skills/bioubt/scripts/e2e_folder.js prob 8 8          # → "8 50/50", errors [], bad []
```
Playwright алдын ала орнатылған (`require(npm root -g + '/playwright')`). Скриншотты өзің Read арқылы қара.
Телефон көрінісін `devices['iPhone 13']` арқылы тексер (сурет, ұяшық, тізім).

## Белгілі тұзақтар (бұрын болған қателер)
- `cloud.js` сақтауда `merge: true` емес, **`mergeFields`** — әйтпесе картадан өшірілген кілт (қате сұрақ) серверде қалады.
- WhatsApp ішкі браузері localStorage-ті өшіреді: прогресс аккаунтқа (`testProg`) да сақталады, құрылғы `deviceFp` арқылы танылады.
- Аяқталған тест нәтижесі серверге жеткенше `bioubt_unsynced_<uid>`-те тұрады; аяқталған тест қайта ашылмайды.
- Мұғалім кабинетінің «Бақылау тестінің нәтижелері» бөлімін мұғалім алып тастатқан — қайта қоспа.
- Оқушылардың Firebase деректерін сен көре алмайсың (мұғалім аккаунты керек) — «жіберіп бер» десе, кабинеттен қалай көруді түсіндір.
- `tools/bump.sh` тек `?v=` нұсқаларын жаңартады; жаңа `<script>` қосқанда да оны іске қос.
